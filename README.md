# Labspace for Developer Productivity


## Instructions



1. Clone your newly created repo to your local machine

```bash
  git clone https://github.com/ajeetraina/labspace-developer-productivity
  cd labspace-developer-productivity
 ```


2. Start the local development mode:

```bash
   # On Mac/Linux
   CONTENT_PATH=$PWD docker compose up --watch
   # On Windows with PowerShell
   $Env:CONTENT_PATH = (Get-Location).Path; docker compose up --watch
```
